# smart-dashboard-data-analytics
An interactive Streamlit dashboard for CSV data analysis, data cleaning, statistical insights, and data visualization.

#  Smart Dashboard Data Analytics

An interactive **Streamlit-based data analytics dashboard** that allows users to upload CSV files and explore, clean, analyze, and visualize their datasets through an easy-to-use web interface.

#  Features

*  Upload CSV datasets
*  View dataset overview
*  Display rows and columns
*  Detect missing values
*  Detect duplicate rows
*  Identify numerical columns
*  Preview complete dataset
*  Search data across the dataset
*  Remove duplicate rows
*  Handle missing values
*  Generate statistical summaries
*  Create multiple visualization types:

  * Bar Chart
  * Line Chart
  * Pie Chart
  * Histogram
  * Scatter Plot
  * Box Plot
* 🔥 Generate correlation heatmaps
* 📋 Analyze categorical columns
* 📥 Download cleaned dataset as CSV

# 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **Pandas**
* **Matplotlib**
* **Seaborn**

# ⚙️ Installation

# 1. Clone the repository

```bash
git clone https://github.com/your-username/smart-dashboard-data-analytics.git
```

# 2. Navigate to the project directory

```bash
cd smart-dashboard-data-analytics
```

# 3. Install dependencies

```bash
pip install -r requirements.txt
```

#  Run the Application

Start the Streamlit application using:

```bash
streamlit run app.py
```

The dashboard will open in your browser.

#  How to Use

1. Launch the Streamlit application.
2. Upload a CSV file.
3. Explore the dataset overview.
4. Search and inspect the data.
5. Apply available data-cleaning options.
6. Select a visualization.
7. Analyze statistics and correlations.
8. Download the cleaned dataset.

#  Dashboard Capabilities

The dashboard provides a simple interface for performing basic **Exploratory Data Analysis (EDA)** without writing separate analysis code for every dataset.

It can be useful for:

* Data exploration
* Data cleaning
* Basic EDA
* Statistical analysis
* Data visualization
* Learning data science concepts
